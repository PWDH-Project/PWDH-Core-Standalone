# PWDH Docker Node Universal

Dieses Bundle läuft auf Linux und macOS mit einem Befehl.

## One-Command

```bash
bash ./install-and-run.sh
```

## Build des Bundles

```bash
bash deploy/node-easy/universal/package.sh
```

## Ausgabe

- `release-artifacts/docker-node-universal/pwdh-docker-node-universal.tar.gz`

## Start/Stop

```bash
./start.sh
./stop.sh
```
